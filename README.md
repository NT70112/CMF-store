# CMF Store

**CMF Store** — учебный многостраничный интернет-магазин, вдохновлённый продукцией CMF.

Основная задача проекта — получить практический опыт работы с **PHP** и **SQLite**.

## Используемые технологии

- **PHP** — обработка запросов, работа с данными и подключение общих модулей страниц.
- **SQLite** — хранение состояния корзины.
- **Fetch API** — передача данных между JavaScript и PHP.

## Что было реализовано

### 1. Динамический каталог товаров

Информация о товарах хранится в отдельном JSON-файле `product-data.JSON`.

JavaScript получает данные из файла, используя `fetch`, и применяет их для динамического формирования HTML-карточек товаров на странице `products`.

Формирование происходит путём прохода по списку объектов. При каждой итерации в HTML-документ создаётся новый объект, который содержит данные текущего объекта цикла.

Каждая карточка содержит собственные изображение, название, стоимость и идентификатор товара. Изменение порядка или добавление новой информации отражается на странице.

### 2. Универсальная страница товара

Для отображения подробной информации используется единый шаблон `product-card.php`.

При переходе из каталога идентификатор выбранного товара передаётся через уникальный URL, который имеет каждая карточка. PHP использует полученный параметр для определения необходимой информации и формирования содержимого страницы.

На странице отображаются:

- Название и стоимость товара.
- Описание и технические характеристики.
- Галерея изображений.
- Вкладки с описанием, характеристиками и отзывами.

### 3. Корзина

Для хранения количества выбранных товаров используется база данных SQLite. В таблице `cart` хранятся идентификатор товара и его количество. Идентификатор выступает первичным ключом.

При нажатии на кнопки добавления или уменьшения количества JavaScript отправляет POST-запрос на PHP-обработчик с помощью Fetch API.

В теле запроса передаются два параметра:

- `productId` — идентификатор товара.
- `action` — действие пользователя.

На стороне PHP выполняются следующие операции:

1. Получение JSON-запроса.
2. Поиск товара в таблице `cart`.
3. Добавление новой записи или изменение существующего количества.
4. Формирование JSON-ответа с обновлённым количеством.

После обработки запроса сервер возвращает результат JavaScript, который использует полученные данные для обновления интерфейса.

### 4. Модульность

Повторяющиеся элементы проекта, такие как `Header` и `Footer`, были вынесены в отдельные модули.

### 5. Страницы и интерактивные элементы

Проект содержит 7 страниц, которые имеют собственные интерактивные элементы.

## Запуск приложения

Для работы проекта необходим PHP с включёнными расширениями **PDO** и **PDO_SQLite**.

Для запуска необходимо запустить локальный сервер:

```bash
php -S localhost:8000
```
